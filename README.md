# Retro City Sudoku

A clean, offline Sudoku game with a restrained retro-city night aesthetic.

## Features
- Easy, Medium, Hard and Expert puzzles
- Mistake tracking and timer
- End-of-game grade based on mistakes and completion time
- Notes mode, erase, hint, pause and restart
- Local best-time and grade records per difficulty
- Works offline

## Build
GitHub Actions builds a debug APK when code is pushed to `main`.
Open the repository's **Actions** tab and download the `retro-city-sudoku-debug-apk` artifact after a successful run.

The output APK is `app-debug.apk`.
